# novanex1
FlashLearn AI is an intelligent learning platform that helps students study effectively by transforming study materials into interactive flashcards. It uses artificial intelligence to generate learning content, supports spaced repetition for better knowledge retention, and provides a structured way to review concepts and track learning progress.
FlashLearn AI is an AI-powered learning platform designed to make studying more interactive, organized, and effective. Users can upload their study materials and use AI to transform them into useful learning resources such as flashcards and review content. The platform supports spaced repetition, helping learners review information at appropriate intervals to improve long-term retention.

The project also includes a structured study session system where users can review flashcards using different difficulty levels such as Again, Hard, Good, and Easy. Each response affects when the card will be shown again, allowing students to focus more on topics they find difficult.

Key features
📚 Upload and manage study materials
🤖 AI-powered generation of learning content
🧠 Interactive flashcard-based learning
🔄 Spaced repetition for long-term retention
🎯 Difficulty-based review system
📊 Study progress and review tracking
👤 User authentication and profiles
☁️ Supabase database and storage integration
💻 Responsive and user-friendly web interface
⚡ React + TypeScript + Vite based application
🔐 Secure server-side handling of AI API requests

Overall, FlashLearn AI aims to combine artificial intelligence, flashcards, and spaced repetition into one platform that helps students turn their own study materials into a more structured and personalized learning experience.
